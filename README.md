# ShuvoniX

The Digital Multiverse. Official website hosted at https://shuvo-nix.github.io

## Structure

- `index.html` - main shell: navigation, footer, page loader
- `css/style.css` - all styles
- `js/main.js` - routing and interactions
- `pages/` - one file per page, edit content here:
  - `home.html`, `about.html`, `services.html`, `benefits.html`, `process.html`, `faq.html`, `portfolio.html`, `blog.html`, `contact.html`

To edit a page, open its file in `pages/`, change the text between the HTML tags, and commit. The site updates automatically.
